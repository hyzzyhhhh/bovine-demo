牛表观组数据库

探索牛的表观组与多组学数据。

牛表观组数据库整合不同组织、品种、发育阶段和生物学条件下的公开测序数据，汇集 Run 元数据、样本与实验信息，以及标准化表观组轨道和关联多组学分析结果。

数据涵盖染色质可及性、组蛋白修饰、DNA 甲基化、三维基因组与转录表达，可按基因、基因组坐标或 Run / Experiment accession 检索，为调控元件发现、候选区域筛选及牛复杂性状研究提供数据参考。
